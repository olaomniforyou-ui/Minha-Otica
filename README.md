# Minha Ótica

Sistema completo de gestão para óticas (ERP, CRM, OS, Financeiro e Estoque).

- 🗺️ **[Roadmap Detalhado](docs/roadmap.md)**: Planejamento estratégico de Sprints e prazos.

## 🚀 Tecnologias

- **Frontend**: Next.js, TypeScript, Tailwind CSS, ShadCN UI.
- **Backend/Banco**: PostgreSQL, Prisma.

## 📂 Estrutura do Repositório

- `/frontend`: Interface do usuário.
- `/backend`: Lógica de servidor e API.
- `/database`: Scripts e migrações do banco de dados.
- `/docs`: Documentação técnica e de negócio.

*Este projeto visa modernizar a gestão de óticas, eliminando controles manuais e centralizando a operação.*
